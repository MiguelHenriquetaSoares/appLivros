##  Descrição do Projeto
Aplicativo mobile desenvolvido com Ionic + Vue.js 3, com foco na construção de interfaces (UI).

O app permite:
- Cadastro de usuário
- Login com validação
- Recuperação de senha
- Visualização de uma lista de livros
- Visualização de detalhes dos livros com capas reais

Os dados são simulados utilizando ref() e localStorage, sem uso de banco de dados ou API externa obrigatória.

---
## 🖥️ Telas Desenvolvidas

-  Tela de Login
-  Tela de Cadastro
-  Tela de Recuperação de Senha
-  Página Home (lista de livros)
-  Página de Detalhes do Livro
